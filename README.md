# e-plantShopping

## Project Name

**e-plantShopping**

## Overview

e-plantShopping is a React-based online plant shopping application. The application allows users to browse a variety of houseplants, add plants to a shopping cart, view selected items, and manage the quantity of items in the cart.

The project demonstrates the use of React components, state management, event handling, and a responsive user interface to create a simple e-commerce shopping experience.

## Features

* Browse different houseplants
* Add plants to the shopping cart
* View selected plants in the cart
* Increase or decrease item quantities
* View the total cost of selected plants
* Remove items from the cart
* Responsive and user-friendly interface

## Technologies Used

* React
* JavaScript
* HTML
* CSS
* Vite
